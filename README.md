# Circle
(주) 그림 과제

메인 화면 입니다.
<img width="860" height="459" alt="image" src="https://github.com/user-attachments/assets/0c73bccc-2d0b-494d-b13a-14be0237568f" />

반지름 란에 숫자를 입력하면 클릭 시 입력값에 해당하는 원을 찍을 수 있습니다.
초기화 버튼을 클릭 시 정원 및 원의 값을 초기화 하여 초기 화면으로 돌아갑니다.

<img width="860" height="459" alt="image" src="https://github.com/user-attachments/assets/ed8d530f-73af-45ab-b843-0f7e29f0c520" />

 Random 버튼을 클릭시 위 와 같이 랜덤한 위치에 0.5초에 한번 총 10회 동작하게 됩니다.

<img width="860" height="459" alt="image" src="https://github.com/user-attachments/assets/548b9614-72d7-446c-ae16-592c11642461" />

점 3개가 일직선에 가까울때 원이 무한히 큰 원으로 가는 상태로 가게 됩니다.
이로 인하여 외적 D= 0 의 기준으로 근삿값 기준으로 큰 원 생성을 막아둔 상태입니다.
